# DSCI 552 Homework 6

Install dependencies with `python -m pip install -r requirements.txt`.
Open `notebook/Zhang_Hanwen_HW6.ipynb` and run all cells from the notebook directory.
The original training and test sets are included as `.csv.gz` files in `data/` and loaded directly using relative paths. No extraction is needed.

On macOS, XGBoost may also require `brew install libomp`.

Data source: [APS Failure at Scania Trucks](https://archive.ics.uci.edu/dataset/421/aps+failure+at+scania+trucks), UCI Machine Learning Repository.
